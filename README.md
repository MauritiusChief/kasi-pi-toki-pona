# 道本之树 kasi-pi-toki-pona

这是一个使用树状结构来将自然语言（中文）解析并转化为toki pona的翻译器。

该项目使用Next.js，未来可能在Vercel上部署。

## 目录结构

- `app/page.tsx`：页面入口，组合各个功能区域。
- `app/api/*`：示例 API Route，占位符逻辑可替换为真实实现。
- `components/`：按功能区拆分的 React 组件，包括 React Context 管理全局状态。
- `hooks/`：相关的 React Hooks。
- `lib/`：工具函数。
- `types/`：共享的 TypeScript 类型定义。

## 结构树

树状结构是用来一级一级将自然语言解析为toki pona的工具，每一级有自己的定义。

- **段落级**：结构树的根，为整个输入文本。
- **句子级**：句子级节点包含“背景”、“主语”、“其他”三个成分，若干个句子级节点在逻辑上组成段落级节点的所有子节点（实际上直接为一整个数组，因为总是只有一个输入文本）。
- **成分级**：成分级节点分为三种，分别对应句子级节点三个成分。
  - **背景节点**：对应toki pona的la结构，为一个数组，其中元素为“从句”或者“名词短语”。其功能一定是交代句子的背景信息。
  - **主语节点**：为一个数组，其中元素只为“名词短语”。其功能顾名思义，表示句子的主语。
  - **其他节点**：为一个数组，其中元素只为“谓语级”节点。其功能是和主语一起表示句子的焦点部分（非背景的部分）。
- **谓语级**：这一级结构是为了分解toki pona的li结构、li...e结构以及相应的介词结构而产生的一级。
  - **简单动作节点**：包含“动词短语”、“名词短语组”、“关系短语组”。顾名思义表示主语进行的动作和动作的对象。
  - **复杂动作节点**：包含“动词短语”、“从句”。功能同上。
  - **简单状态节点**：包含“状态短语”、“关系短语组”。顾名思义表示主语的状态。
  - **复杂状态节点**：包含“从句”。功能同上。
- **短语组级**：仅用来处理包含多个“名词短语”或“关系短语”的部分。
  - 名词短语组：元素为“名词短语”的数组。
  - 关系短语组：元素为“关系短语”的数组。
- **短语级**：
  - 动词短语：包含一个前动词和一个动词。
  - 名词短语：包含一个中心词和若干修饰结构，每个修饰结构包含一个中心修饰词和若干子修饰词。
  - 状态短语：本质上就是名词短语，为了方便理解才将其称为“状态短语”。
  - 关系短语：包含一个关系词和一个名词短语。也就是toki pona中被称为“介词短语”的类别。由于toki pona中的介词与中文中的介词含义有差异，故称之为“关系词”，以方便理解。
  - 从句：

由于从句的存在，需要额外引入类似主句的结构树。

- **从句成分级**：类似，除了“从句背景节点”元素不可为“从句”。
- **从句谓语级**：不包含复杂xx节点（本质上是排除从句嵌套）。
- **从句短语组级**：类似。
- **从句短语级**：类似，除了不可为“从句”。
